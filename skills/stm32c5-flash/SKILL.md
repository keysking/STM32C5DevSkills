# STM32C5 烧录

按本次需求选择下列场景及参考章节，不把整篇资料当成执行清单。命令中的型号、引脚、数值和名称用于说明语法，须替换为真实需求及当前工程的值；只执行所选操作和必要依赖，查询任务不顺带修改配置。

1. 明确本次固件对应的完整 C5 型号、构建结果、目标板与探针。多探针时按序列号选择，不能任取第一个。
2. 按[下载步骤](references/program.md)定位 `cube programmer` 或原生 `STM32_Programmer_CLI`，读取帮助并列出探针。
3. 连接后确认实际器件、Flash 容量和预期一致。ELF/HEX 自带地址；BIN 需要从工程链接布局确定地址，不能只按“STM32 默认地址”猜。
4. 选择本次固件格式的一条下载路径并校验；需要启动应用时在校验成功后复位或运行。记录校验结果，并根据应用可观测行为确认启动。
5. 连接失败按[连接与恢复](references/recovery.md)逐级排查供电、SWD、复位和速率。涉及读保护解除、全片擦除、选项字节或安全配置时，先具体解释影响并取得该动作的授权。

完成标准：正确目标、正确文件与地址、下载和校验成功、启动结果分别说明。没有连接硬件时只检查命令与产物，明确未执行板端烧录。
