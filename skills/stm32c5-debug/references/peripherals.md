# 中断、DMA 与外设异常

按数据路径逐层取证，不一次修改时钟、引脚、DMA 和回调。

| 观察 | 下一步 |
| --- | --- |
| 引脚无变化 | GPIO 复用、输出使能、外设时钟、实际封装和电路 |
| 外设有数据/状态，但 IRQ 不进 | 外设中断源、pending、NVIC、向量、PRIMASK/BASEPRI |
| IRQ 进入但回调不进 | 实际 HAL IRQHandler、handle、标志清除、注册宏/签名 |
| DMA 计数不动 | 请求选择、方向、通道使能、外设触发、地址可访问性 |
| DMA 完成但应用无数据 | 回调、缓存条件、缓冲区寿命、消费与覆盖 |
| 第一次成功后停止 | 普通/循环模式、重新启动、错误状态、Busy 所有权 |

UART：先轮询发送固定字符串检查波特率，再固定长度 IT，最后 DMA/IDLE。关注 overrun、frame/noise、IDLE 长度语义和是否重复重启。

I2C：观察 START、地址 ACK、时钟拉伸和 STOP；查 7 位/左移地址约定、上拉与从机复位。不要在 ISR 中进行总线恢复或长超时轮询。

SPI：检查 CS 前后时序、CPOL/CPHA、数据宽度、SCK 和 RX overrun。DMA 完成与最后一位上总线的时刻未必相同。

TIM/PWM：检查 CNT、PSC、ARR、CCR、GPIO AF、通道输出使能、TIM1 break/MOE。CNT 在计数而引脚无 PWM 时重点查通道/GPIO，不先重写时钟。

ADC：区分 ADC active、校准完成、转换触发、EOC/EOS、DMA 数据宽度和输入电压。参考电压、采样时间和源阻抗都会影响结果。

使用逻辑分析仪/示波器时将实际采样频率、通道接线和协议设置与固件参数对应。没有测量设备可先通过寄存器和计数缩小范围，但不能虚构总线波形。

配置修复回到[对应实例](../../stm32c5-configure/SKILL.md)，保存重载并合并生成差异；代码修复后构建新 ELF 并验证原触发条件。
